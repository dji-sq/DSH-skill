# 网页信息提取流程

当用户给出一个 URL 和想要的信息类型时，按以下步骤执行。

## 第一步：确认抓取能力
先检查当前会话是否有可用的网页抓取工具（如 web_fetch）。如果没有，直接告诉用户“当前环境没有开启网页抓取能力”，并停止流程。不要假装抓取了内容。

## 第二步：抓取页面
调用可用的抓取工具获取 URL 的正文内容。如果抓取失败（超时、403、内容为空），如实报告失败原因，不要编造内容。

## 第三步：提取信息
根据用户指定的信息类型，从正文中提取相关内容。
- 如果用户要的是“某一段话”，直接引用原文，不要改写。
- 如果用户要的是“列表/条目”，逐条列出，保留原始顺序。
- 如果用户要的是“数字/日期/名称”，只输出找到的值，并标注它在原文中的上下文（前后各一句话）。
-“日期”指页面上可见的日期文本，包括 YYYY-MM-DD、YYYY/MM/DD、中文年月日、英文月份名等格式。不提取页脚版权年份，不提取 HTML 元数据中的日期。

## 第四步：输出格式
用以下格式输出：

**抓取状态**：成功 / 失败（附原因）
**页面标题**：[如果抓到了就填，没抓到写“未知”]
**提取结果**：
- [按用户要求的信息类型组织]

- 不要总结页面全文，只提取用户要的信息。
